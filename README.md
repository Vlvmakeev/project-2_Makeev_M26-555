# Название проекта

Проект представляет собой самописную примитивную базу данных, реализованную через хранение данных в файлах и имплементированную в виде CLI-приложения.

Пользователь может создавать, просматривать список и удалять базы данных.

---

## Использование

### Управление таблицами

#### `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...`

Создать таблицу.

**Пример запроса:**

    create_table users name:str age:int is_active:bool

**Пример ответа:**

    Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

---

#### `drop_table <имя_таблицы>`

Удалить таблицу.

**Пример запроса:**

    drop_table users

**Пример ответа:**

    Таблица "users" успешно удалена.

---

#### `list_tables`

Показать список всех таблиц.

**Пример запроса:**

    list_tables

**Пример ответа:**

    - users

---

#### `info <имя_таблицы>`

Вывести информацию о таблице.

**Пример запроса:**

    info users

**Пример ответа:**

    Таблица: users
    Столбцы: ID:int, name:str, age:int, is_active:bool
    Количество записей: 0

---

### Операции с данными

#### `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)`

Создать запись.

**Пример запроса:**

    insert into users values ("Sergei", 28, true)

**Пример ответа:**

    Запись с ID=1 успешно добавлена в таблицу "users".

---

#### `select from <имя_таблицы> where <столбец> = <значение>`

Прочитать записи по условию.

**Пример запроса:**

    select from users where age = 28

**Пример ответа:**

    +----+--------+-----+-----------+
    | ID |  name  | age | is_active |
    +----+--------+-----+-----------+
    | 1  | Sergei | 28  |    True   |
    +----+--------+-----+-----------+

---

#### `select from <имя_таблицы>`

Прочитать все записи.

**Пример запроса:**

    select from users

**Пример ответа:**

    +----+----------+-----+-----------+
    | ID |   name   | age | is_active |
    +----+----------+-----+-----------+
    | 2  |  Sergei  |  44 |    True   |
    | 3  |  Alan    |  35 |   False   |
    | 4  |  Kevin   |  22 |   False   |
    | 4  |  Elliot  |  65 |   False   |
    +----+----------+-----+-----------+

---

#### `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>`

Обновить запись.

**Пример запроса:**

    update users set age = 29 where name = "Sergei"

**Пример ответа:**

    Запись с ID=1 в таблице "users" успешно обновлена.

---

#### `delete from <имя_таблицы> where <столбец> = <значение>`

Удалить запись.

**Пример запроса:**

    delete from users where ID = 1

**Пример ответа:**

    Запись с ID=1 успешно удалена из таблицы "users".

---

## Разработка

### Требования

Для установки и запуска проекта необходимы:

- Python >= 3.12
- [uv](https://docs.astral.sh/uv/) >= 0.12.13, < 0.13.0
- Poetry >= 1.2.0
- Ruff

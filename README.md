# Название проекта
Проект представляет собой самописную примитивную базу данных через хранение в файлах, которое имплементировано в CLI-приложение.
Пользователь может создавать, получать список и удалять базы данны

## Использование
Пользователь может управлять таблицами:

create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. - создать таблицу:
(пример запроса) create_table users name:str age:int is_active:bool
(пример ответа) Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

drop_table <имя_таблицы> - удалить таблицу:
(пример запроса) drop_table users
(пример ответа) Таблица "users" успешно удалена.

list_tables - показать список всех таблиц:
(пример запроса) list_tables
(пример ответа) - users


## Разработка

### Требования
Для установки и запуска проекта, необходимы:
python3 >= 3.12
poetry >= 1.2.0
ruff

### Установка зависимостей
Для установки всех необходимых зависимостей проекта, выполните команду:
```sh
make install
```

### Запуск проекта
Для запуска приложения в виртуальном окружении, выполните команду:
```sh
make project
```

### Сборка пакета
Для сборки дистрибутивов проекта (архива и wheel-файла) в директорию `dist`, выполните команду:
```sh
make build
```

### Тестовая публикация
Для проверки готовности пакета к публикации (в тестовом режиме, без фактической загрузки на сервер), выполните команду:
```sh
make publish
```

### Установка собранного пакета
Для локальной установки собранного пакета (wheel-файла) из директории `dist`, выполните команду:
```sh
make package-install
```

### Проверка кода (линтинг)
Для проверки кода на соответствие стандартам и поиска потенциальных ошибок с помощью Ruff, выполните команду:
```sh
make lint
```
